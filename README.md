# Aria Assistant

## Estrutura
- Backend (Python): Gemini Live + ações + WebSocket
- Frontend (Vite/React/Three.js): HUD + transcrição + painel

## Rodar
### Backend
- criar Backend/.env (use Backend/.env.example)
- python -m venv venv
- pip install -r requirements.txt
- python main.py

### Frontend
- criar Frontend/.env (use Frontend/.env.example)
- npm install
- npm run dev
